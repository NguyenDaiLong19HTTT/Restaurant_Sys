# Thanh toán trong bản tích hợp

Xem [hợp đồng đang chạy](../integration/CONTRACTS.md), [cấu hình VNPay](../integration/VNPAY.md) và [hướng dẫn stack tích hợp](../../README.md). ORDER_ADAPTER=http và TABLE_ADAPTER=http; dữ liệu bàn/order lấy từ owner thật. Các file hợp đồng cũ ORDER-CONTRACT/TABLE-CHECKOUT được giữ để đối chiếu, ưu tiên hợp đồng bản tích hợp khi có điểm khác.
