# Luồng chọn bàn — bản tích hợp

Chọn bàn theo branch trong token → chọn rõ một order chưa trả tiền → xem món/số lượng/đơn giá snapshot/tổng → Thanh toán → voucher → tiền mặt/VNPay. Không tự chọn/gộp order. Bàn và order lấy qua HTTP owner thật, không dùng demo adapter trong service chính. Xem [hợp đồng](../integration/CONTRACTS.md), [quy trình kiểm thử](../../README.md#kiểm-thử), [cấu hình VNPay](../integration/VNPAY.md).
