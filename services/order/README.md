# Order trong bản tích hợp

Nguồn order.zip được tích hợp với menu và reservation thật. Thu tiền chỉ thuộc payment-service; settle và order_payments đã bị loại. Xem [hợp đồng và retry](../../docs/integration/CONTRACTS.md), [bảng API](../../docs/integration/API-MATRIX.md), [chạy stack](../../README.md). Migration do service chạy bằng user order_app, không truy cập schema khác.
